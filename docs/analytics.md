# Аналитика (Яндекс Метрика / GTM) и согласие на cookie

## Где живут ID счётчиков

Одно место на лендинг и приложение — строка `landing_config` (key = `current`)
в основной БД, поля `yandex_metrika_id` и `gtm_id` в `payload`. Её отдаёт
`GET /api/landing-config` (кэш в Redis 60 с, ключ `landing:config`).

- Лендинг: `apps/landing/assets/analytics.js` (подключён на всех страницах).
- Приложение: `apps/aivita/app/[locale]/layout.tsx` → `AivitaMetrika`.

Редактора в админке нет — меняется SQL-ом:

```sql
UPDATE landing_config
SET payload = payload || '{"yandex_metrika_id": "12345678"}'::jsonb,
    updated_at = now()
WHERE key = 'current';
```

После этого сбросить кэш, иначе до минуты будет отдаваться старое:

```bash
redis-cli DEL landing:config
```

GTM — так же, поле `gtm_id` вида `GTM-XXXXXXX`. Пустое значение или его
отсутствие — тег не грузится.

## Согласие

- Cookie `aivita_consent` = `granted` | `denied` на `.aivita.uz`, срок год —
  общий для aivita.uz и app.aivita.uz.
- Баннер (текст + «Принять» / «Отклонить») показывается, только если
  настроен хотя бы один счётчик и ответа ещё нет.
- До «Принять» Метрика и GTM не загружаются вообще; «Отклонить» — не
  загружаются никогда (пока человек не очистит cookie).

## Как проверить, что данные пошли

1. Открыть aivita.uz в приватном окне, нажать «Принять».
2. В DevTools → Network должен появиться запрос
   `mc.yandex.ru/watch/<ID>` с ответом 200. Для подробностей — открыть
   страницу с `?_ym_debug=1`: Метрика пишет в консоль каждый отправленный хит.
3. В интерфейсе Метрики визит виден в отчёте «Посещаемость» за сегодня
   (обычно через несколько минут) и в «Посетители → Сейчас на сайте».
